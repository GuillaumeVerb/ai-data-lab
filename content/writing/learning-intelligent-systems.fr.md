## Où j’en suis

La base data est ancienne et publique (pipelines, lake, warehouse — projets de formation 2021). 2025 a servi de terrain on-chain. 2026 a produit des copilotes (analyse tabulaire, RAG grounded, automation HITL). Physical AI est une **direction**, pas un livrable.

## Ce qui a une preuve

Decision Copilot, Knowledge Copilot, dashboard on-chain, automation agent, et les labs d’eval / HITL / notes Physical AI. Voir Learning : nœuds marqués « avec preuve ».

## Ce qui n’en a pas

MCP serveur, ROS2, simulation, VLA en run. Les nœuds Learning « en cours » existent pour ne pas masquer le trou.

## Méthode

Pas de jauge « Python 90% ». Une compétence n’entre dans le graphe que reliée à un projet, un lab, une note ou une eval. Le reste reste du vocabulaire.
